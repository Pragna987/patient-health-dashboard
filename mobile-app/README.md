# Patient Health Dashboard (Mobile App)

React Native + Expo application for tracking personal health records, medications, appointments, and lab results.

## Tech Stack
- React Native (Expo)
- Firebase Authentication + Firestore
- React Navigation
- Context API

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and add Firebase values.
3. Run app:
   ```bash
   npm start
   ```

## Folder Highlights
- `src/screens`: feature screens
- `src/components`: reusable UI components
- `src/services`: Firebase and domain services
- `src/context`: app-level state providers
- `src/navigation`: auth and app navigation
