# Patient Health Dashboard

A mobile-first Patient Health Dashboard project scaffold with React Native (Expo), Firebase integration placeholders, and optional Node.js backend structure.

## Repository Structure

```text
patient-health-dashboard/
├── mobile-app/
├── backend/
└── docs/
```

## Core Features Included
- Authentication (Firebase-ready service placeholders)
- Dashboard overview screen
- Health records tracking screens
- Medication tracker screens
- Appointment management screens
- Lab results screen
- Profile management screen

## Quick Start
1. Open `/home/runner/work/patient-health-dashboard/patient-health-dashboard/mobile-app`
2. Install dependencies: `npm install`
3. Configure environment from `.env.example`
4. Start Expo: `npm start`

For optional backend setup and detailed guides, see:
- `/home/runner/work/patient-health-dashboard/patient-health-dashboard/docs/SETUP.md`
- `/home/runner/work/patient-health-dashboard/patient-health-dashboard/docs/FEATURES.md`
- `/home/runner/work/patient-health-dashboard/patient-health-dashboard/docs/API_REFERENCE.md`
