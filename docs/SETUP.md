# Setup Guide

## Prerequisites
- Node.js 18+
- npm 9+
- Expo Go app (for physical device testing)
- Firebase project (Auth + Firestore enabled)

## Mobile App Setup
1. Go to `/mobile-app`
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Add your Firebase configuration values
5. Start with `npm start`

## Optional Backend Setup
1. Go to `/backend`
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Run `npm run dev`
